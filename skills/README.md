# skills/ —— 系统内置只读资源（区域③）

此目录是全体成员只读共享的系统技能库，对应《AI Agents in Depth》Ch2/Ch4 的
**Skills：领域能力的可组合单元**，以及 Ch10 虚拟文件系统的「系统内置资源」层。

## 约定

- 每个技能 = 一个目录：`skills/<skill-name>/SKILL.md`（索引/触发条件/要点）+ 可选的详细文档与脚本。
- **只读**：成员不得写 `skills/`；技能修订走「最小 diff + 可回滚」流程（PLAN M7），
  并只能用版本化目录（`skills/<name>-v<N>/`，只增不改）。
- **渐进式披露**：成员上下文只加载 `SKILL.md` 索引或目录列表，需要时再读取细节内容。
